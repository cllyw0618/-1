IntraHC 交互分析系统

高阶关系数据
智能聚类分析平台

以超图建模为核心，将场景选择、结构发现、节点解释与风险定位整合到同一套交互式分析流程中。

系统基于超边内判别增强与划分级聚类指导，帮助用户从复杂关系数据中识别群体结构、边界节点与潜在跨簇风险。

Analysis Flow 三步完成交互分析
01 场景选择 切换论文、新闻、属性网络等多类高阶关系数据。
02 结构发现 识别群体结构、跨簇超边与稳定高置信簇。
03 节点解释 定位局部邻居、共享超边和边界风险来源。

方法说明

系统采用 CAHC-style contrastive pretraining、attribute-guided intra-hyperedge repulsion 与 latent dynamic cut regularization 的端到端分析流程。

当前页面展示训练结果子集（shown_node_count / node_count），以保证移动端可视化与交互流畅。

节点使用匿名 ID 展示，不使用真实名称与真实标签参与交互解释。
